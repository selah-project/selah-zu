# Ukubamba iqhaza ekuhumusheni kwesiZulu kweSelah

Siyabonga — ngokwenza lokhu kuhumusha kucace kakhudlwana, kube sobala kakhudlwana, kusondele kakhudlwana esiZulwini. Akudingeki ube isazi: yisho okubonile, letha izizathu zakho, futhi hlukanisa okucacile kokucabangelayo.

## Bika noma uphakamise

- Uma igama lidinga ingxoxo, noma kukhona ukufundwa okungaphezu kokukodwa — vula i-**Issue**.
- Uma iphutha nokulungiswa kwalo kucacile kokubili — vula i-**Pull request**.
- Ngemibuzo yesofthiwe noma yokuphepha — [Selah Support](https://selahproject.com/support).

## Imithetho yokulungisa amafayela

Amafayela asesimweni `<book>/<chapter>/<verse>.json`.

- Uma ushintsho luthinta kokubili — lungisa i-`translation` ne-`gloss` ehambisanayo kanyekanye.
- I-`book`, `chapter`, `verse`, `ref`, i-`surface` yesiHebheru, kanye nokuhleleka nenani lamathokheni — **akushintshwa nanini**. Ukwephula ukuqondanisa — yiphutha elikhulu kunawo wonke.
- **Ngokwetafula lamagama**: יהוה → **uYahwe**; אלהים → **uElohim**; אדני → **u-Adonayi**; שדי → **uShadayi**; שאול → **iSheol**; חסד → **ikhesedi**. Esihlalweni segama **uJehova**, **uNkulunkulu**, **iNkosi**, **uSimakade** akwamukelekile. (Ngo-*elohim* ojwayelekile — onkulunkulu, onkulunkulu bezizwe — nquma ithokheni ngethokheni. Ngamakhosi abantu — inkosi, umnumzane — *inkosi* ilungile.)
- Gcina uphawu **⟨את⟩** namagama okugcwalisa ⟨asezibiyelweni⟩; ungawashiyi ngokuthula. Amagama okugcwalisa abe **ngesiZulu**.
- Ngaphandle kwezibiyelo — isiZulu esicacile: azikho izingezelelo zesiNgisi, azikho izinhlamvu zolunye uhlamvu-mibhalo (ngaphandle kuka-⟨את⟩).

## Ukusebenza nge-AI

Uma usebenzise imodeli enkulu yolimi noma ukuhumusha ngomshini — kusho ngokusobala, kanye nokubuyekeza kwakho. Ungathumeli imibhalo engabuyekeziwe ngobuningi.
