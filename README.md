# ImiBhalo eNgcwele yesiHebheru (iTanakh) — ukuhumusha ngesiZulu

Ukuhumusha kwesiZulu kwemiBhalo eNgcwele yesiHebheru (iTanakh) — ivesi ngevesi, ngokwethembeka ezinhlamvini zombhalo.

## IsiHebheru — kuqala

Lokhu kuhumusha kukhona ukuze kukuyise esiHebherwini — hhayi ukuthatha indawo yaso. Okufundwa njalo yisiHebheru: izinhlamvu zaso, imisindo yaso, izimpawu zaso. Umbhalo wesiZulu ongezansi uyifasitela, hhayi umbambeli. Uma kwehlukana, iqiniso likusiHebheru.

## Igama

Lapho igama lezinhlamvu ezine limi khona, sibhala **uYahwe** — asikho isiqu, alikho igama elijwayelekile elithatha indawo yalo. Asibhali **uJehova** (isimo esixubile), asibeki **uNkulunkulu** (igama elijwayelekile) esihlalweni segama, asibhali **iNkosi** nokuthi **uSimakade** (iziqu — zisusa igama). Igama lihlala njengoba linjalo yonke indawo — ukuze kubonakale njalo lapho igama limi khona. Isiqalo **u-** (uYahwe, uElohim) siwuhlelo lolimi lwesiZulu, hhayi ukushintshwa kwegama.

## I-alefu-tawu — ⟨את⟩

Emishweni yesiZulu uzothola uphawu **⟨את⟩**. EsiHebherwini u-אֵת uyigama elincane elikhombisa ukuthi isenzo senziwa kubani. IsiZulu asinalo elifana nalo ngqo, futhi ukuhumusha okuningi kuyalishiya ngokuthula. Thina siyaligcina ezibiyelweni, ukuze libonakale — liyingxenye yokwakheka kolimi lwesiHebheru. Esikhundleni sokulishiya, sikhethe ukubonisa ubukhona balo.

## Amagama ⟨asezibiyelweni⟩

Izibiyelo zalolu hlobo ⟨kanje⟩ zikhombisa igama **elingekho esiHebherwini** — amagama okugcwalisa adingwa umusho wesiZulu. Ngaphakathi kwezibiyelo kunesiZulu kuphela.

## Amagama obuNkulunkulu neziqu

Amagama esiHebheru abhekise koNgcwele — **uElohim**, **u-El**, **uShadayi**, **u-Adonayi**, **uYah** — abhalwa ngomsindo wawo. Asiwahlanganisi abe yigama elilodwa; ngalinye lithwala umthwalo walo. Amagama abantu namadolobha nawo alandela isimo sesiHebheru: u-Avraham, uYitshaki, uYakobi, uMoshe, iYerushalayim.

## Amagama aphawuliwe

- **ikhesedi** (חֶסֶד) — uthando lwesivumelwano olungapheli. Hhayi nje "umusa", hhayi nje "isihe". Alikho igama elilodwa lesiZulu elilithwala.
- **iSheol** (שְׁאוֹל) — indawo yabafileyo, njengoba isiHebheru sisho. Hhayi nanini "isihogo".
- **uMashiya** (מָשִׁיחַ) — **ogcotshiwe** — ezingeni leTanakh, hhayi nanini "uKristu".
- **inefeshi**, **uruwahi**, **ikavodi** — ngokwendawo yawo (umphefumulo noma ukuphila, umoya noma umoya-wokuphefumula, inkazimulo noma isisindo) — awaboshwa egameni elilodwa.

## Ivesi ngalinye ekukhanyeni kwalo

Ivesi ngalinye lisho lokho elikushoyo endaweni yalo — silifunda ekukholweni kwesiHebheru kokuthi uElohim munye. Asiyihudulisi emuva imfundiso yakamuva; asifundi isiphetho sendaba esiqalweni sayo.

## Ukuhleleka kwamafayela

Ivesi elilodwa — ifayela elilodwa: ivesi uqobo nokuhumusha kwegama ngalinye eduze kwesiHebheru salo — ukuze igama ngalinye lesiHebheru lifundwe libhekene negama lalo lesiZulu.
